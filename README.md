# Raspberry Pi project

This repository contains a small multi-language setup with Python and C examples.

## Structure

- `src/python/hello.py` - Python hello example
- `src/c/hello.c` - C hello example
- `Makefile` - build and run helpers

## Commands

- `python3 src/python/hello.py`
- `make build-c`
- `make run-python`
- `make run-c`
- `make clean`
